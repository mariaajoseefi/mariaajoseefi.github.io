Pokémon Web Redesign

A semester-long team project reimagining Pokémon Emerald as a browser-playable game. Working in weekly/biweekly sprints with an instructor acting as client, I was part of a team redesigning the game's UI for web, balancing modernized layout and spacing with the nostalgic feel of the original pixel art.

1. Understanding the problem

Pokémon Emerald was designed for a console — a D-pad, a fixed button layout, a small fixed-resolution screen. Bringing it to the browser meant every part of the interface needed to work naturally with a mouse and keyboard, without losing what made it feel like Pokémon.

2. Working in sprints with a real client

Our instructor acted as the client, giving us structured, real-world constraints and feedback throughout the semester. Working in weekly/biweekly sprints meant designing, presenting, and iterating continuously — closer to an actual studio workflow than a typical solo class project.

3. Redesigning for web constraints

Redesigned the bag and overworld interface to work with mouse-and-keyboard interaction while keeping the visual language recognizable to anyone who'd played the original game, and designed new login and home page screens to support user accounts on web.

4. Balancing nostalgia and modernization

Kept the original pixel art to preserve the game's identity, while modernizing layout and spacing to feel more natural in a browser — clearer visual hierarchy, better use of screen space, and interactions suited to a mouse instead of a D-pad.

5. Testing and iterating

Gathered feedback from both user testing sessions and client/instructor review each sprint, using it to refine the interface across the semester rather than designing once and finalizing.
