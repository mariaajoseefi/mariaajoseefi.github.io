Morph

A Python CLI tool built to solve a real personal problem: moving photos off a digicam meant manually renaming files, sorting duplicates, and organizing everything by hand. Morph automates that, with commands for bulk renaming, duplicate detection, file organization by extension, CSV analysis, and a full undo system backed by a history log.

1. The problem

Every time I moved photos off my digicam, I'd spend way too long manually renaming files, sorting duplicates, and organizing everything by hand. I wanted a faster, repeatable way to do it.

2. Research

Looked into existing file-management tools and CLI design patterns to figure out what a lightweight, scriptable solution would actually need, and used it as an opportunity to learn Python packaging and CLI development properly, from scratch.

3. Building

Built a Python CLI using Click (command structure) and Rich (readable terminal output), with a real project structure; pyproject.toml for packaging, virtual environments, and pytest for testing. Implemented commands for bulk file renaming, duplicate detection, file organization by extension, CSV analysis, and an undo system backed by a history log, so nothing gets lost by mistake.

4. Debugging and iterating

Worked through real setup challenges along the way — Anaconda environment conflicts, pip/pyproject.toml compatibility issues, import path corrections, and logic bugs — refining commands based on actual use with my own photo dumps.

5. Next steps

Still working on: PyPI publishing, CI, a demo GIF, and additional commands. With the long-term goal of publishing it as a polished open-source project.
